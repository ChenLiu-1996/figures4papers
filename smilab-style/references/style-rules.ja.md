# smilab-style ルール（v2・日本語レビュー用）

**位置づけ**：smilab-style は既存の [scientific-figure-making](../../scientific-figure-making/SKILL.md) を**ベース**とし、その上に「上書き 3 点」と「追加ルール」を重ねる差分の skill です。ここに書いていないことは、すべてベースのルールに従います。

参照図：`images/01_…` 〜 `33_…`（本文中の `#NN`）。

## 1. ベースから継承（変更なし）

| ベースのルール | smilab での扱い |
|---|---|
| 青 `#0F4D92` ＝提案手法、緑＝改善、赤系＝比較・対照、ニュートラル＝背景 | **維持**。提案手法の派生版（アブレーション）は薄い青 `#B7CAE2`, `#6F94BE` |
| 配色は青・緑・赤・ニュートラル系の中から選ぶ | **維持**。比較手法のパステル色も同系統（figure_MACL で使っている色） |

| y 軸範囲をデータに合わせて詰める | 維持（下端の値は軸上に必ず見えるように） |
| 凡例で手法が分かるときは x 目盛を消す | 維持 |
| アブレーションは同じ色の濃淡、白黒印刷用にハッチ | 維持 |

## 2. ベースを上書きする 3 点（確認済み）

### O1 フォント
- ベース：Helvetica / Arial
- smilab：**論文に入れる図は Times New Roman ＋ STIX 数式**。本文の LaTeX と馴染ませるため（#01–05, #12–17）。ティーザーやスライドだけサンセリフ（ベースのフォント）を使う。1 枚の図の中ではフォントは 1 系統。
- 数式は論文と同じ記法（太字斜体のベクトル $\boldsymbol{X}$、立体の添字 $\boldsymbol{x}_\mathrm{txt}$）。

### O2 サイズ
- ベース：45×12 in のような大きなキャンバスに 16〜24pt、太さ 2〜3pt で描いて縮小する。
- smilab：**実寸で描く**。1 段組 ≈ 3.3 in、2 段組 ≈ 7.0 in、文字 7〜9pt（最小 6pt）、軸線 0.8pt。印刷時の文字サイズが確定し、図どうしで揃う。ベースの「横に広く並べて左から右へ読ませる」構図はそのまま使う。

### O3 棒グラフと凡例
- ベース：値は棒の上に大きく、黒い太枠、凡例は枠なし。
- smilab（CANDLE 風、#14–16）：
  - 値は**棒の中に縦書き**（下端寄り、濃い色の棒では白字）。棒の上はエラーバーと星のために空けておく。
  - 枠線は黒ではなく**同じ色相の少し濃い色**の細線。
  - 凡例は**細いグレー枠付き**で、マーカーは**四角**、提案手法は**太字**。
  - **薄い y グリッド**（`#E6E6E6`）。
  - 有意差はエラーバーの上に `*`（p<.05）`**`（p<.01）`***`（p<.001）。

## 3. ベースにない追加ルール

- **A1 論文単位の一貫性**：手法と色の対応表を論文で 1 つ作り、全図で使う（#14–17）。模式図のモジュールと色、アイコンの意味も同様。
- **A2 軸ラベル**：`名前 [単位] ↓/↑`（例 `HD95 [mm] ↓`）。良い方向は軸ラベルに書き、タイトルには書かない。
- **A3 凡例・ラベル**：提案手法は最後に置いて太字。複数パネルは共通凡例を上に 1 行（#10）または右に 1 列（#14）。散布図は凡例を使わず点の横に同色で名前を書く（#05）。折れ線は色とマーカーの両方を変え、提案手法を一番手前にやや太く描く。
- **A4 横棒アブレーション**（#17）：完全版は青、派生版は薄い青（ベースの濃淡ルールを継承）。太字のグループ見出し、`(b-i) w/o fθ` のような番号付きの行、列ごとの最良値を太字、星は右端、タスク群の間に縦線。
- **A5 模式図の配色**：淡い塗り＋同じ色相の濃い枠（ベースの配色系統から作った `TONES`）。色は概念ごとに固定し、提案手法の出力や強調には青を使う（ベースと一致）。グラデーションは「2 つの状態の混合」を表すときだけ。詳細は [schematics.md](schematics.md)。
- **A6 アイコン・記号**：✗ 赤 / ✓ 緑、❄ 凍結 / 🔥 学習可能（ブロックの左上）、👤 人間評価。
- **A7 ティーザー（Fig. 1）**：既存手法 ✗ vs 提案手法 ✓、具体例を入れる、下にスコアボックス（提案手法は太字・太枠、人間評価と ≈ で並べる）（#08, #22）。
- **A8 やらないこと**：大面積のベタ塗り、3D、強い影、意味のない色を 6 色以上、本文と異なる記法、スペルミス（参照図にも "Hierachical" #07、"Attentnion" #26、"Sculp" #12 がある → 書き出し前にスペルチェック）。

## 付録：参照図が綺麗に見える理由（追加ルールの根拠）

1. **色が少なく、意味を持っている**：1 枚あたり 3〜5 色相で、1 概念＝1 色を論文全体で固定。
2. **淡い塗り＋同じ色相の濃い枠**：色数が多くてもうるさくならない。
3. **主役と脇役の差**：提案手法や新しいモジュールだけに色・太字・太枠を使い、既存部品や比較手法は控えめにする。
4. **本文と同じ数式記法**を図中でも使う。
5. **実データのサムネイル**（スペクトログラム、脳表、動画フレーム）で、何が入って何が出るかを見せる。
6. **グリッドに揃っている**：同じ種類のブロックは同じサイズ・同じ間隔、直角配線。
7. **模式図とプロットで同じ視覚表現を使う**（DISCODE の数字バッジ #28–30、CANDLE の手法色 #12–17）。
